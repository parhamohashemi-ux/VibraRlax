# VibraRelax (original Kotlin project)
1. Open this folder in Android Studio (Koala or newer) and let Gradle sync.
2. Build > Build Bundle(s) / APK(s) > Build APK(s).
3. APK: app/build/outputs/apk/debug/app-debug.apk
Features: intensity slider, 6 patterns, timer, foreground service (runs with screen off), stop from notification.
Note: needs a phone with a vibration motor; emulators don't vibrate.
